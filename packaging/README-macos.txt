Signal Viewer for macOS

1. Extract this archive.
2. Move "Signal Viewer.app" to Applications if desired.
3. Open "Signal Viewer.app".
4. Choose a .csv, .u16, or .f32 signal file in the app.

This package targets Apple silicon Macs. It does not contain signal data.
It is ad-hoc signed, but not Developer ID signed or notarized. The first
launch may require approval in macOS Privacy & Security.
